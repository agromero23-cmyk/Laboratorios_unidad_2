# Actividad 10 — Política de retención

## Pregunta 1. ¿Es compatible con el principio de minimización?

No. Conservar todos los datos de los clientes indefinidamente no es compatible con una adecuada minimización de datos, porque la información debe conservarse únicamente durante el tiempo necesario para cumplir una finalidad específica. Que los datos puedan ser útiles en el futuro no es una justificación suficiente para mantenerlos sin límite.

## Pregunta 2. ¿Qué riesgos genera conservar información innecesaria?

Conservar información innecesaria genera varios riesgos:

- **Filtraciones de datos:** aumenta la cantidad de información que podría quedar expuesta ante un ataque.
- **Accesos no autorizados:** los datos pueden ser consultados indebidamente.
- **Incumplimiento de privacidad:** conservar información sin una justificación válida puede contravenir las obligaciones aplicables.
- **Costos de almacenamiento:** mantener datos innecesarios ocupa espacio y recursos.
- **Uso indebido:** la información podría utilizarse para finalidades distintas de aquellas para las que fue recopilada.
- **Dificultad para eliminar datos:** mientras más copias existan, más complicado será atender solicitudes de cancelación.

## Pregunta 3. ¿Qué debería determinar la organización antes de establecer un periodo de retención?

La organización debería determinar:

- La finalidad para la que se recopilaron los datos.
- El tiempo durante el cual los datos son necesarios para cumplir esa finalidad.
- Las obligaciones legales o fiscales que exijan conservar determinada información.
- Los riesgos de seguridad y privacidad asociados con los datos.
- Si es posible eliminar, anonimizar o bloquear la información cuando deje de ser necesaria.
- El procedimiento para revisar periódicamente los datos almacenados.

## Pregunta 4. ¿Qué información debería documentarse para justificar el periodo seleccionado?

| Elemento | Justificación |
|---|---|
| Tipo de dato | Permite identificar qué información se conservará. |
| Finalidad | Explica por qué se necesita conservar el dato. |
| Periodo de retención | Establece durante cuánto tiempo se mantendrá la información. |
| Fundamento legal | Identifica las obligaciones que justifican la conservación, cuando corresponda. |
| Responsable | Indica quién supervisa el cumplimiento de la política. |
| Método de eliminación | Define cómo se eliminarán o anonimizarán los datos cuando termine el periodo. |
| Revisión periódica | Permite comprobar si la conservación sigue siendo necesaria. |
| Excepciones | Documenta los casos en los que sea necesario conservar información por obligaciones legales o procedimientos pendientes. |

## Conclusión

La organización no debería conservar todos los datos de sus clientes indefinidamente solo porque podrían ser útiles en el futuro. Debe establecer periodos de retención según la finalidad de cada dato y las obligaciones aplicables. Cuando la información deje de ser necesaria, deberá eliminarse, anonimizarse o bloquearse según corresponda.

Una política documentada permite reducir riesgos, proteger la privacidad de los clientes y administrar los datos de manera responsable.
